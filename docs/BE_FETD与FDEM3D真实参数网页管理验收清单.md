# BE_FETD 与 FDEM3D 真实参数网页管理验收清单

- [ ] BE Grounded/Loop 两个 GB18030 真实样例可解析并规范 roundtrip。
- [ ] FDEM Grounded/Loop 两个 UTF-8 真实样例可解析并规范 roundtrip。
- [ ] 页面可切换两个程序及两种源，正确显示时间/频率、材料、几何和接收点。
- [ ] 上传文件只加载表单；保存后才更新当前镜像与 exe 工作目录。
- [ ] 用户可直接从真实默认参数开始编辑和保存。
- [ ] 两标签页旧 SHA 保存返回 stale revision，当前文件不被覆盖。
- [ ] 活动任务期间保存返回 workspace busy。
- [ ] 程序同步不覆盖用户已保存的四个当前参数文件。
- [ ] 提交页不再要求 `.dat` 上传，仍严格发送 stdin 1/2。
- [ ] 任务提交时 staging 同时快照该程序两个当前文件，所选 DTO/hash 写入 Task。
- [ ] 排队后的当前编辑不改变 staging 和最终 archive。
- [ ] 成功、失败、取消、超时及恢复后两个工作副本等于当前镜像。
- [ ] 历史列表按用户、程序和源类型隔离，跨用户访问返回 404。
- [ ] 历史版本另存当前后，archive 文件 SHA-256 不变。
- [ ] 旧真实归档经只读识别后可加载；无效旧格式只可下载。
- [ ] 迁移 dry-run、备份要求、占位备份、未知文件不覆盖通过。
- [ ] 后端全量 pytest、前端 production build、四条 Mock E2E 通过。
