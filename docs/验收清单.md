# 验收清单（T9.2）

验收方式：「自动」= pytest 已有用例覆盖（59 个用例，`cd backend && pytest`）；「手工」= 启动服务后按步骤操作核对。

## 认证与账户（FR-AUTH）

- [ ] FR-AUTH-01 开放注册，注册后为待验证状态（自动：test_auth）
- [ ] FR-AUTH-02 验证邮件链接 24h 有效，未激活不能登录（自动；**SMTP 实发需手工核对一次**）
- [ ] FR-AUTH-03 登录返回 JWT（自动）
- [ ] FR-AUTH-04 忘记密码 → 邮件 → 重置 → 旧密码失效（自动；SMTP 实发手工核对）
- [ ] FR-AUTH-05 用户中心改用户名（查重 409）、改密码（验旧密码）（自动）
- [ ] FR-AUTH-06 管理员重置密码，返回一次性临时密码（自动）

## 参数配置（FR-PARAM）

- [ ] FR-PARAM-01 参数 Schema 驱动（自动：test_param_schema）
- [ ] FR-PARAM-02 前端表单化编辑 + 校验（手工：提交任务页）
- [ ] FR-PARAM-03 后端二次校验 + 序列化参数文件（自动）
- [ ] FR-PARAM-04 模板增删改查、同名 409（自动）
- [ ] FR-PARAM-05 从历史任务复制参数重新提交（手工：详情页按钮）

## 上传（FR-UPLOAD）

- [ ] FR-UPLOAD-01 上传大小限制（默认 200MB 可配，超限 413）（自动）
- [ ] FR-UPLOAD-02 记录原始文件名（自动）

## 队列（FR-QUEUE）

- [ ] FR-QUEUE-01 状态机与失败原因记录（自动）
- [ ] FR-QUEUE-02 FIFO（自动：test_fifo_order）
- [ ] FR-QUEUE-03 最大并发 50 可配（自动：test_global_concurrent_limit / test_config_update_takes_effect）
- [ ] FR-QUEUE-04 单用户运行 ≤3、排队 ≤3，超限 429（自动）
- [ ] FR-QUEUE-06/07 用户取消排队中/运行中任务（自动）
- [ ] FR-QUEUE-08 超时自动终止（默认 60 分钟可配）（自动：test_run_timeout）
- [ ] FR-QUEUE-09 服务重启恢复：残留 RUNNING → FAILED + 通知（自动）

## 执行（FR-EXEC）

- [ ] FR-EXEC-01~05 子进程执行、stdout/stderr 落盘、退出码判定、时间与快照记录（自动）
- [ ] **真实 program.exe 跑通完整流程（手工，依赖实验室物料）**

## 历史与结果（FR-HIST）

- [ ] FR-HIST-01/02 任务列表、详情（自动）
- [ ] FR-HIST-03 四类文件下载、越权 404（自动）
- [ ] FR-HIST-04 前端 5s 轮询 + 手动刷新（手工）
- [ ] FR-HIST-05 运行时长 / 排队位置展示（自动 queue_position；前端展示手工核对）

## 通知（FR-NOTIFY）

- [ ] FR-NOTIFY-01 完成/失败/被终止产生站内通知（自动）
- [ ] FR-NOTIFY-02 未读数、标记已读（自动）

## 管理后台（FR-ADMIN）

- [ ] FR-ADMIN-01 仪表盘统计与资源使用率（自动）
- [ ] FR-ADMIN-02/03 运行中/排队任务列表与终止（自动）
- [ ] FR-ADMIN-04 用户增删改查、禁用/启用、删除级联清文件（自动）
- [ ] FR-ADMIN-05 重置密码（自动）
- [ ] FR-ADMIN-06 系统参数在线调整即时生效（自动）
- [ ] FR-ADMIN-07 审计日志留痕可查（自动）
- [ ] FR-ADMIN-08 禁用用户：不能登录、排队任务取消、运行中不动（自动）

## 清理（FR-CLEAN）

- [ ] FR-CLEAN-01 超保留期任务记录 + 文件删除（自动：test_cleanup）
- [ ] FR-CLEAN-02 清理动作写日志（自动日志；手工核对后端输出）

## 非功能

- [ ] 50 并发压测雏形：脚本并发提交 60 个 Mock 任务，验证排队与限额（手工/脚本）
- [ ] 部署手册在一台干净机器可复现（手工）
