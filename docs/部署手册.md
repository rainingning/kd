# 部署手册（Windows 单机）

目标环境：一台 Windows 服务器，Web 后端、PostgreSQL、Fortran 计算程序同机部署。

## 1. 环境依赖

| 依赖 | 版本 | 说明 |
|---|---|---|
| Python | ≥ 3.11（开发用 3.14） | 后端运行 |
| PostgreSQL | 17 | 结构化数据 + 任务队列 + 文件元数据 |
| Node.js | ≥ 20 | 仅构建前端时需要 |
| Fortran 计算程序 | program.exe | 实验室提供，Windows 可执行 |

## 2. 数据库准备

```sql
CREATE DATABASE fortran_platform TEMPLATE template0;
```

> 若报 `collation version mismatch`，用 `TEMPLATE template0` 绕过，
> 或先执行 `ALTER DATABASE template1 REFRESH COLLATION VERSION;` 再正常建库。

## 3. 后端部署

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r backend\requirements.txt
```

在仓库根目录创建 `.env`（所有配置项见下表，均有默认值，按需覆盖）：

| 配置项 | 说明 | 示例 |
|---|---|---|
| DATABASE_URL | PG 连接串 | `postgresql+asyncpg://postgres:密码@127.0.0.1:5432/fortran_platform` |
| JWT_SECRET | JWT 签名密钥，**生产必改** | 随机长字符串 |
| FORTRAN_COMMAND | 计算程序命令模板，`{params}`/`{data}` 为占位符 | `"C:/lab/program.exe" {params} {data}` |
| STORAGE_ROOT | 任务文件存储根目录 | 默认 `仓库根/storage` |
| SMTP_HOST / SMTP_PORT | 邮件服务器 | `smtp.exmail.qq.com` / `465` |
| SMTP_USER / SMTP_PASSWORD | 邮箱账号 / 授权码 | |
| SMTP_FROM | 发件人地址 | 默认同 SMTP_USER |
| SMTP_USE_TLS | 默认 `true` | |
| APP_BASE_URL | 平台对外地址（拼接邮件链接用） | `http://server:8000` |

> SMTP 未配置时平台可运行，但验证/重置邮件只会写入后端日志，用户无法激活——公网开放前必须配置。

初始化数据库并创建管理员：

```bat
cd backend
..\.venv\Scripts\python -m alembic upgrade head
cd ..
.venv\Scripts\python scripts\create_admin.py admin admin@example.com --password <强密码>
```

启动服务：

```bat
scripts\start_backend.bat
```

服务监听 8000 端口。若 `frontend/dist` 存在，后端自动托管前端，单端口即可访问。

## 4. 前端构建

```bat
cd frontend
npm install
npm run build
```

产物 `frontend/dist` 由后端自动托管；`npm run dev` 仅用于开发（已配置 `/api` → `localhost:8000` 代理）。

## 5. 开机自启（NSSM 注册 Windows 服务）

1. 下载 NSSM（https://nssm.cc）
2. 注册服务：
   ```bat
   nssm install FortranPlatform "D:\path\to\kd\.venv\Scripts\python.exe" "-m uvicorn app.main:app --host 0.0.0.0 --port 8000"
   nssm set FortranPlatform AppDirectory "D:\path\to\kd\backend"
   nssm set FortranPlatform AppStdout "D:\path\to\kd\logs\backend.log"
   nssm set FortranPlatform AppStderr "D:\path\to\kd\logs\backend.log"
   nssm start FortranPlatform
   ```

## 6. 真实计算程序接入（上线前关键步骤）

1. 将实验室提供的参数清单与文件格式规范落到 `backend/app/param_schema/schema.json`（字段：name/type/required/default/min/max/options/description）
2. 在 `backend/app/param_schema/service.py` 的 `serialize_params` 中实现真实格式（当前为 JSON，供 Mock 使用；代码中有 TODO 标记）
3. `.env` 的 `FORTRAN_COMMAND` 指向真实 `program.exe`
4. 用真实参数文件 + 真实数据文件跑通一次完整任务验证（见验收清单）

## 7. 运维要点

- **备份**：`pg_dump fortran_platform` + 备份 `storage/` 目录（保留期内的任务文件）
- **日志**：uvicorn 标准输出（NSSM 已重定向）；调度、任务状态迁移、清理动作均有日志
- **系统参数**（并发数、单用户限额、超时、保留期、上传上限）：管理员登录后台在线调整，即时生效，无需重启
- **服务重启**：运行中任务会被标记为"服务重启中断"并通知用户，排队任务自动继续
- **定期清理**：每天自动删除超过保留期（默认 30 天）的任务记录与文件

## 8. 目录约定

```
kd/
├── backend/          # FastAPI 后端（alembic 迁移在 backend/alembic）
├── frontend/dist/    # 前端构建产物（后端自动托管）
├── storage/          # 任务文件：storage/{user_id}/{task_id}/
├── scripts/          # create_admin.py / start_backend.bat
├── mock/             # Mock 计算程序（开发联调用）
└── .env              # 环境配置（不入库）
```
